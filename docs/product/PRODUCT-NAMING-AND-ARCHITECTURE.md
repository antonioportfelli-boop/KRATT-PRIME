# Product Naming and System Hierarchy

**Status:** Proposed canonical naming decision for review

## Naming

- **3XTRINITY:** ecosystem and organization identity.
- **KRATT PRIME:** governed AI control plane, policy authority, agent orchestration, typed memory and evidence.
- **NEURO-ORGANIC POLYMORPHIC CORE (NOPC):** subordinate adaptation layer for user interaction and authorized agent workflows.
- **TARK MEES TASKUS:** human-facing Android/iOS mobile application.

## Relationship

TARK MEES TASKUS → KRATT PRIME API → Policy & Authorization → Agent Orchestration / Typed Memory / Evidence / Adapters

NOPC operates inside the KRATT PRIME governance boundary. It may propose adaptive presentation or workflow changes, but all protected actions remain subject to Core policy and authorization.

## Naming rules

- Use **TARK MEES TASKUS** as the visible mobile app name.
- Use tark-mees-taskus as a provisional repository/documentation slug only.
- Do not invent a package identifier, bundle identifier, publisher name or trademark claim. Confirm ownership and availability before release.
- Keep AURA, STEEL, FRAME.9 and CERBERUS as distinct components; this product naming decision does not merge or rename those projects.

## Status and evidence

This file records a product/architecture proposal. It does not establish that the mobile application or NOPC runtime has been implemented. Implementation status must be supported by source files, tests, builds and review evidence.
